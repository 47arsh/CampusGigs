# CampusGigs Frequently Asked Questions

## What is CampusGigs?

CampusGigs is a campus marketplace where students can post and complete small tasks for other students.

---

## Who can create a task?

Registered and authenticated CampusGigs users can create tasks.

A task creator should provide a clear description, reward, pickup location and drop location where applicable.

---

## Who can accept a task?

Authenticated users can accept tasks that are currently open.

A user should review the task details before accepting it.

---

## Can I accept a task without reading its description?

Users should always review the description, reward, locations and requirements before accepting a task.

Accepting a task indicates that the user intends to complete the requested work.

---

## What happens when I accept a task?

The task changes from an open marketplace task to an assigned task.

The accepting user becomes the user responsible for completing it.

---

## What happens after I complete a task?

The assigned user can mark the task as completed.

A completed task is no longer an available marketplace gig.

---

## What if I cannot complete an accepted task?

If a user realizes that they cannot complete an accepted task, they should cancel it as soon as reasonably possible.

Repeated or unnecessary cancellations can reduce trust within the marketplace.

---

## Can I create any kind of task?

No.

Tasks must be safe, legal and appropriate for the campus environment.

Tasks involving prohibited, dangerous or inappropriate activities should not be created.

---

## Can a task involve prohibited items?

No.

CampusGigs should not be used to request, transport or exchange prohibited items.

---

## Can I create a task involving dangerous activity?

No.

Users should not create or accept tasks that create unreasonable safety risks.

---

## Can I create a task for academic misconduct?

No.

CampusGigs should not be used to facilitate cheating, impersonation, unauthorized examination assistance or other academic misconduct.

---

## Why does CampusGigs use task statuses?

Task statuses make it clear whether a gig is:

- available
- assigned
- completed
- cancelled

This helps prevent confusion between task creators and task performers.

---

## Can I accept multiple tasks?

A user should only accept tasks that they can realistically complete.

Users should consider time, location and existing commitments before accepting additional gigs.

---

## What information should I include when posting a task?

At minimum, a useful task should clearly communicate:

- What needs to be done
- Where the item should be picked up
- Where it should be delivered
- The reward
- Any important instructions

---

## How should I handle a disagreement about a task?

Users should preserve relevant task details and other available evidence.

If the platform provides a support or dispute process, users should use that process.

---

## Is CampusGigs responsible for university rules?

CampusGigs is a marketplace application.

University, hostel, examination and other institutional rules may exist separately from CampusGigs policies.

Users should follow applicable official university rules and policies.

---

## What should I do if the CampusGigs AI cannot answer my question?

The AI assistant only knows information available in its configured knowledge base.

If it cannot find sufficient information, users should consult the appropriate official source rather than assuming the AI's answer.
