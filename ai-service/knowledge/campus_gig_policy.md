# CampusGigs Task Policy

## Purpose

CampusGigs allows students to create and complete small campus-related tasks or gigs for other students.

Examples include:

- Delivering notes between campus locations
- Collecting an item from a campus location
- Helping another student transport a permitted item
- Picking up a document
- Completing other safe, legal and campus-appropriate errands

---

## Creating a Task

A task creator should provide enough information for another student to understand the gig before accepting it.

A task should normally contain:

- A clear title
- A useful description
- The expected reward
- Pickup location
- Drop location
- Any important instructions

Task descriptions should not intentionally hide important requirements.

A task should be safe, legal and appropriate for the campus environment.

---

## Accepting a Task

Only authenticated CampusGigs users can accept an open task.

Once a task is accepted:

- The task is assigned to the accepting user.
- The task should no longer be treated as an unassigned marketplace task.
- The assigned user is responsible for completing the task according to the description.

Users should review the task description before accepting it.

---

## Task Completion

After successfully performing the task, the assigned user can mark the task as completed.

A completed task should not continue to appear as an available open gig.

Users should only mark a task as completed after the requested work has actually been performed.

---

## Task Cancellation

Users should avoid cancelling an accepted task unless cancellation is necessary.

Before accepting a task, users should consider whether they can reasonably complete it.

Repeated or inappropriate cancellations may negatively affect trust within the marketplace and may lead to future platform restrictions.

If a user cannot complete an accepted task, they should cancel it as soon as reasonably possible rather than leaving the task unresolved.

---

## Task Statuses

CampusGigs tasks may have the following statuses:

- `open` — available for a user to accept
- `accepted` — assigned to a user
- `completed` — successfully completed
- `cancelled` — cancelled before completion

---

## Multiple Tasks

A user should only accept tasks that they can realistically complete.

Before accepting additional tasks, users should consider:

- Their available time
- Task locations
- Task deadlines or expected completion time
- Whether the tasks can be completed without interfering with existing commitments

---

## Disputes

If there is a disagreement about a task, users should preserve relevant information such as:

- Task description
- Messages or instructions
- Completion details
- Relevant timestamps

Disputes should be handled through the platform's designated support process when such a process is available.

---

## Summary

CampusGigs is designed around three principles:

1. Clear task descriptions
2. Responsible acceptance and completion
3. Safe and respectful campus interactions
