# CampusGigs Safety Guidelines

## Purpose

CampusGigs tasks should help students with ordinary campus activities without creating unnecessary risks.

Safety should take priority over completing a gig.

---

## Safe Task Principles

A task should generally be:

- Legal
- Campus-appropriate
- Reasonably safe
- Clearly described
- Possible to complete without specialized dangerous equipment

Users should not feel pressured to perform an unsafe task simply because they accepted it.

---

## Prohibited Task Categories

CampusGigs should not be used for tasks involving:

- Weapons
- Explosives
- Illegal substances
- Dangerous chemicals
- Unauthorized access to restricted areas
- Theft or concealment of stolen property
- Harassment
- Threats
- Academic misconduct
- Other clearly unlawful activities

---

## Restricted Locations

Users should not enter restricted or unauthorized areas to complete a gig.

A task creator should not ask another student to bypass access controls or security procedures.

---

## Personal Information

Users should avoid unnecessarily sharing sensitive personal information.

A task should request only information reasonably necessary to complete the gig.

Users should be cautious when sharing:

- Passwords
- Authentication codes
- Financial credentials
- Private documents
- Personal identification information

---

## Financial Safety

Users should be cautious about tasks involving money.

A user should not be asked to:

- Provide banking credentials
- Share passwords or OTPs
- Transfer money for suspicious purposes
- Participate in financial fraud

---

## Academic Safety

CampusGigs must not be used to facilitate academic misconduct.

Examples include:

- Completing an examination for another student
- Impersonating another student
- Providing unauthorized examination assistance
- Circumventing academic security procedures

---

## When a Task Becomes Unsafe

If a user discovers that a task is unsafe or violates platform rules, they should not continue simply because they previously accepted it.

The user should prioritize personal safety and report the issue through the appropriate support process.

---

## Safety First

The purpose of CampusGigs is to make campus life easier.

No gig reward justifies unnecessary danger or illegal activity.
