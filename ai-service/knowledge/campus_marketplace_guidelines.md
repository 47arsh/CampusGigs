# CampusGigs Marketplace Guidelines

## Marketplace Philosophy

CampusGigs is designed around cooperation between students.

A good marketplace task should be:

- Clear
- Honest
- Reasonably scoped
- Safe
- Respectful

---

## Task Quality

A high-quality task description should answer:

1. What needs to be done?
2. Where should the task start?
3. Where should it end?
4. What reward is offered?
5. Are there any important constraints?
6. When should it be completed?

Vague task descriptions can lead to misunderstandings.

---

## Rewards

Task creators should specify the reward clearly before another user accepts the task.

Users should evaluate whether the reward is appropriate for the work, time and travel involved.

---

## Locations

Pickup and drop locations should be described clearly.

If a location has access restrictions, the task creator should mention this rather than assuming the task performer already knows.

---

## Communication

Task creators and task performers should communicate respectfully.

Important changes to a task should be communicated clearly.

Users should not pressure another user into performing work that was not reasonably described when the task was accepted.

---

## Changes to a Task

If important details change after acceptance, the affected users should communicate before continuing.

Examples of important changes include:

- A different pickup location
- A different drop location
- A significantly different item
- A different completion requirement
- A materially different time requirement

---

## Cancellation

Cancellation should be communicated as early as possible.

If a task can no longer be completed, leaving the other user without an explanation can create unnecessary problems.

---

## Trust

The marketplace depends on reliable behavior.

Users can build trust by:

- Creating accurate tasks
- Accepting tasks they can complete
- Completing tasks responsibly
- Communicating when circumstances change
- Avoiding repeated unnecessary cancellations

---

## Respect

CampusGigs should not be used for:

- Harassment
- Threats
- Discrimination
- Intimidation
- Personal disputes
- Abusive requests

Users should treat other participants respectfully.

---

## Disputes

A disagreement should not be escalated through threats or harassment.

Users should preserve relevant information and use available platform support mechanisms.

---

## Marketplace Summary

The goal of CampusGigs is simple:

Make it easier for students to help one another with small, legitimate campus tasks while keeping the marketplace safe and trustworthy.
